Why did ETH Zurich researchers declare visual CAPTCHAs dead?

In September 2024, ETH Zurich researchers demonstrated that standard YOLOv8 computer vision models solve reCAPTCHA v2 puzzles with 100% accuracy, requiring fewer retries (2.71) than real human beings (3.50). Commercial solving APIs crack these puzzles in under 800 milliseconds for $0.0008. Distorted images only create friction for real customers, not bots.

Will AttestOS slow down legitimate visitors?

No. Legitimate human users with modern devices (iOS, macOS, Android, Windows) pass in 0ms via silent hardware Secure Enclaves or Apple/Google Private Access Tokens. Clients without biometric hardware solve a light WebCrypto mathematical challenge in ~80ms in background with zero human puzzles.

How does the 24-hour fast-pass session cookie save quota?

Once a visitor completes hardware attestation or Ghost-PoW, the Cloudflare worker issues an HMAC-signed session cookie (attestos_session). For the next 24 hours, all requests from that client are admitted immediately at the edge in <0.01ms CPU time, consuming zero verification quota.
