Developer Architecture & API Reference Manual

Cryptographic specifications, stateless HMAC challenge flows, and Cloudflare Edge API contracts.

1. Stateless Proof-of-Work Algorithm (WebCrypto)

Ghost-PoW operates entirely in native client WebCrypto with zero external libraries:

// Client solves dynamic challenge in background without UI freezing
const encoder = new TextEncoder();
let nonce = 0;
while (true) {
  const hashBuf = await crypto.subtle.digest('SHA-256', encoder.encode(salt + nonce));
  const hex = Array.from(new Uint8Array(hashBuf)).map(b => b.toString(16).padStart(2, '0')).join('');
  if (hex.startsWith('0'.repeat(difficulty))) {
    return { salt, nonce, hash: hex, difficulty };
  }
  nonce++;
}

2. Fast-Pass 24-Hour Attested Session Cookie

Verified clients receive an HMAC-signed session cookie:

Set-Cookie: attestos_session={sessionData}.{hmacSig}; Path=/; Max-Age=86400; SameSite=Lax; HttpOnly

Subsequent requests bypass pipeline compute completely, conserving >90% of free tier quotas.
