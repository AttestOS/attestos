# Allow, charge or block each crawler category

Deciding what AI crawlers can read your content can be tricky. You want to allow legitimate crawlers while keeping others out. With robots.txt rules, you can specify which crawlers are allowed to access your site, but this can be cumbersome to manage. 

Training, search, and live fetchers have different needs. Verified crawlers should get crawler treatment, while others should be blocked or charged. AgentPass Pro allows per-category decisions, crawler IP verification, and HTTP 402 paid crawling. You can also issue metered agent keys and use Private Access Tokens for secure access.
