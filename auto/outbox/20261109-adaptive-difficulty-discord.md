# Raise the cost only when traffic surges

channel: discord
kind: value

Adaptive difficulty can help prevent abuse on your SaaS platform. Fixed difficulty is either annoying all the time or too weak during an attack. Measure normal solves per minute, add work when the rate jumps, and drop back automatically when it calms down. This approach raises the cost for attackers only when traffic surges, making it more efficient. Consider using proof of work, risk scores, and passkeys to enhance security, and implement server-side token verification with single use, expiry, and error codes to prevent API key farming.
