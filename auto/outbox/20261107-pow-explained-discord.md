# Proof of work in one paragraph

channel: discord
kind: value

Proof of work slows automated form submissions by making the browser solve a small hashing puzzle before submitting. Each extra bit of difficulty doubles the work, so one solve is cheap, but a million are not. It's invisible to humans, but slows attackers, without identifying them. This can be used in conjunction with risk scores to flag suspicious activity and adaptive difficulty to adjust the puzzle's complexity based on user behavior.
