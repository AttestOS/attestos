# Watch verify failures after every launch

channel: tumblr
kind: value

When building client sites, it's crucial to monitor verify failures after every launch. A spike in failed verifies can indicate either an attack or a broken integration, both of which require attention. To tackle this, baseline the failure rate in week one, then set up alerts for any significant jumps. Before assuming it's an attack, check the error codes - they might reveal a simple integration issue. Regularly reviewing verify failures helps identify potential problems early on, allowing for swift action to prevent spam incidents.
