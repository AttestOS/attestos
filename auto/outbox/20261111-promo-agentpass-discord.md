# Allow, charge or block each crawler category

channel: discord

Deciding what AI crawlers can read on your site can be complex. You can set rules per crawler in your robots.txt file, but this doesn't account for training, search, or live fetchers. Verifying crawlers by their published IP ranges can help, but not all crawlers publish this info. With AgentPass Pro, you can allow, charge, or block each crawler category, and even use HTTP 402 for paid crawling. You also get crawler IP verification and metered agent keys. Check the docs to learn more about fine-grained control over your site's content: https://attestos-edge.attestos.workers.dev/go/robots?src=c-promo-agentpass
