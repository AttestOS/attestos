# Proof of work in one paragraph

channel: discord
kind: value

Proof of work slows down abuse by making each request slightly expensive. In a browser, it solves a small hashing puzzle before submitting a form. One solve is cheap, but a million solves are not. This invisible check raises the cost of each attempt, making it harder for attackers to abuse your signup or API key forms. It doesn't identify them, but slows them down. Pair it with server-side token verification, using single-use tokens that expire, and return specific error codes. Risk scores can help fork legitimate traffic from suspicious activity, while passkeys and adaptive difficulty add extra layers of security. Check your forms for weaknesses and consider implementing these measures to prevent abuse.
