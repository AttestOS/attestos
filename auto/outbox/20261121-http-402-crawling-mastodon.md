# HTTP 402 lets you charge crawlers instead of blocking them

channel: mastodon
kind: value

HTTP 402 allows paid crawling, a middle ground between blocking and free access. Return 402 with key purchase info, meter requests per key, and keep search crawlers on their normal path. Verifying crawlers by IP range or Private Access Tokens can also help manage access.
