# Proof of work in one paragraph

channel: mastodon
kind: value

Proof of work slows attackers by making each request costly. It's a small hashing puzzle solved by the browser before submitting a form, invisible to humans. One solve is cheap, but a million are not. This defence raises the cost of abuse, making API key farming and signup abuse more expensive.
