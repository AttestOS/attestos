# Blocking training does not have to block search

channel: tumblr
kind: value

When deciding what AI crawlers can access your content, consider the purpose of each crawler. Search crawlers like Googlebot help your site appear in search results, while training crawlers gather data for AI models. Live fetchers update content in real-time. You can set specific robots.txt rules for each type of crawler. 

List the crawlers and their purposes: search, training, live fetching. Decide per category, not per company, as multiple crawlers may serve the same purpose. Review this list when new crawlers appear. 

Verifying crawlers by published IP ranges can help ensure only authorized crawlers access your site. You can also charge for crawling using HTTP 402 or offer paid access with agent keys. Private Access Tokens provide an additional layer of control. By distinguishing between search and training crawlers, you can maintain search visibility while controlling model training data.
