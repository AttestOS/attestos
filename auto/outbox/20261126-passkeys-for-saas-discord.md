# Passkeys remove the password attackers reuse

channel: discord
kind: value

Passkeys remove the password attackers reuse. A passkey is a public-private key pair, with the private key stored securely on the user's device. Offer passkeys at signup and after login, keeping a recovery path that's not weaker than the passkey. This way, even if an attacker gets a user's password, they can't use it to access the account. Implement server-side token verification with single-use tokens, expiry, and error codes to prevent API key farming. Consider proof of work and risk scores to fork suspicious traffic, and adaptive difficulty to slow down attackers.
