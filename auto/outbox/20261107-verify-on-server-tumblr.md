# A widget that is never verified on the server is decoration

channel: tumblr
kind: value

Abuse reaches store forms in various ways: card testing at checkout, credential stuffing on login, fake accounts and promo farming, gift-card guessing. A visible puzzle may seem like a solution, but it comes at a cost to real buyers. For every attempt it stops, it also frustrates genuine customers. A better approach is to verify on the server, where a token can be checked without hindering the user experience. The siteverify call checks the secret, token, age, and single use, providing a more robust defense. By rejecting requests when the call fails, you can prevent abuse without putting a burden on legitimate buyers. This approach is especially important for online stores, where a smooth checkout process is crucial for conversions.
