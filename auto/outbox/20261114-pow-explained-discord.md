# Proof of work in one paragraph

channel: discord
kind: value

Proof of work slows automated form submissions by making the browser solve a small hashing puzzle before submitting. Each extra bit of difficulty doubles the work, so one solve is cheap, but a million are not. This invisible check doesn't identify attackers, it just raises the cost of each attempt. It's not a replacement for server-side verification, which should use single-use tokens, expiry, and clear error codes. Risk scores can help fork suspicious traffic, while passkeys and adaptive difficulty add extra layers of security. Check your own forms to see if they're vulnerable to abuse.
