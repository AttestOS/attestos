# Passkeys remove the password attackers reuse

channel: discord
kind: value

Passkeys remove the password attackers reuse. A passkey is a public-private key pair, unique to each user and device. Offer passkeys at signup and after login, keeping a recovery path that's not weaker than the passkey. This prevents shared secret leaks and reuse. For API key farming, use server-side token verification with single use, expiry, and error codes. Proof of work and risk scores can also help, with adaptive difficulty adjusting to suspicious activity. Implementing passkeys and these measures can help prevent abuse and strengthen security.
