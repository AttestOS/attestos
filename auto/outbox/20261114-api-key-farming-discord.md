# Free API keys attract key farms

channel: discord
kind: value

Free API keys can attract key farms, where scripts sign up for multiple accounts to exploit your service. To spot this, look for many accounts with a single usage pattern. Gate the key behind a verified action, like a server-side token verification with single use, expiry, and error codes. Meter usage by account and by key to detect anomalies. Consider using proof of work, risk scores, or passkeys to add a layer of security, and adaptive difficulty to make it harder for scripts to sign up. Verify actions, not just accounts.
